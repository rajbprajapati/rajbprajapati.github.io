- **Pre-Rendered Static HTML (SSG)**: Sub-second First Contentful Paint (FCP) and Time To First Byte (TTFB).
- **Zero Layout Shift (`CLS: 0`)**: Self-hosted Google Fonts via `next/font` (Geist Sans & Geist Mono) eliminate font-swapping layout jank.

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajbprajapati/rajbprajapati.github.io.git
   cd rajbprajapati.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Compile the production static export:**
   ```bash
   npm run build
   ```
   The compiled static website will be generated in `out/`.

## 🚢 Automated GitHub Pages CI/CD

Deployment is completely automated via GitHub Actions in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

### First-Time Setup on GitHub:
1. Navigate to **Settings** > **Pages** in your repository.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `master` (or `main`):
   ```bash
   git push origin master
   ```
4. GitHub Actions will automatically install dependencies, build the Next.js static export, and deploy to **`https://rajbprajapati.github.io`**.
